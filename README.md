# 📝 Todo Task Management App

A **cross-platform Todo Task Management App** built using **Flutter** and **Firebase**, designed to help users manage personal tasks effortlessly.

This project was developed as part of a hackathon organized by [Katomaran](https://www.katomaran.com).

---

## 📘 Project Overview

This mobile app enables users to create, manage, and track their personal to-dos with a clean and responsive interface. 

Users authenticate via **Firebase Authentication**, and all their tasks are stored locally using **SQLite**, securely scoped to their user account.

---

## 🔐 Key Features

- 🔑 **Firebase Authentication**  
  Supports login via Email/Password and Google Sign-In.

- 👤 **User-specific Task Lists**  
  Each user sees only their own tasks after logging in.

- ✅ **Task Management (CRUD)**  
  Create, Read, Update, and Delete tasks with ease.

- ⚡ **Task Attributes**  
  - Title  
  - Description  
  - Priority (High / Low)

- 💾 **Local Persistence**  
  Offline task storage using SQLite with automatic sync after login.

- 🎨 **Modern UI/UX**  
  - Responsive layout for all screen sizes  
  - Profile display at the top  
  - Smooth animations and transitions  
  - Real-time validation for input fields

- 🔐 **Session Management**  
  - Persistent login  
  - Secure logout and navigation handling
