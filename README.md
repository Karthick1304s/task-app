📘 Project Overview
This is a cross-platform Todo Task Management App built using Flutter and Firebase, designed to help users manage personal tasks efficiently. It supports full task CRUD operations (Create, Read, Update, Delete), with task attributes like title, description, priority, and due date.

Each user gets their own private task list based on Firebase Authentication. Once logged in, a user can add and manage tasks that are securely stored locally using SQLite, filtered by their unique user ID. The app offers a clean and responsive UI with real-time validation, smooth navigation, and intuitive controls.

🔐 Key Features
Firebase Authentication (Email/Password or Social Login)

User-specific task lists

Add, edit, and delete tasks

Task priorities: High / Low

Local database with SQLite

Responsive and polished UI

Profile display at top of task list

Logout and session management
